# SKEV Blender Toolkit
Blender addon for importing CAT files from Senran Kagura: Estival Versus

## Installing

1. Download [latest release]( https://github.com/bluesnowball18/skev-blender-toolkit/releases/download/v1.0/skev-blender-toolkit-1-0.zip )
2. Open Blender
3. Go to Edit > Preferences > Add-ons
4. Press Install and choose your ZIP file
